# Soft-constrained Schrödinger Bridge: a Stochastic Control Approach

> Garg, Zhang, Zhou (Texas A&M), AISTATS 2024。[arXiv:2403.01717](https://arxiv.org/abs/2403.01717)

## 一句话

把 SB 的硬终端约束换成对目标分布的 KL 惩罚（SSB），用随机控制方法证明最优受控过程的终端分布是「目标分布与参考终端分布的几何混合」$\propto\mu_T^{\beta}\,\nu^{1-\beta}$——GSB 软化终端约束的另一条严格推导，也是「鲁棒生成」的理论基础。

## 问题与动机

标准 SB 要求终端分布**恰好**等于目标 $\mu_T$。两个现实问题：(1) 目标本身可能被污染（离群样本），精确匹配意味着把污染也学进去；(2) 控制代价与匹配精度之间没有权衡旋钮。随机控制里的自然做法是把硬约束换成惩罚项——终端可以偏离目标，但按 KL 付费。

## 方法核心

SSB 问题：在受控扩散 $dX_t=(b_t+u_t)dt+\sigma dW_t$ 上最小化

$$
\mathbb{E}\Big[\int_0^T\tfrac{1}{2}\|u_t\|^2dt\Big] + \beta\,\mathrm{KL}\big(\mathbb{P}^u_T\,\|\,\mu_T\big)
$$

- 第一项是控制能量（Girsanov 下等于路径 KL），第二项是终端 KL 惩罚，$\beta$ 权衡。$\beta\to\infty$ 退回硬约束 SB。
- **主定理**：最优受控过程的终端分布是几何混合 $\mathbb{P}^{u^*}_T\propto\mu_T^{\,\beta/(1+\beta)}\cdot\nu^{\,1/(1+\beta)}$（$\nu$ 为无控参考过程的终端分布，指数形式随论文归一化约定略有差异）。直觉：软约束下最优解不是「部分到达目标」而是「到达一个介于目标与参考之间的分布」，且是几何而非算术插值——目标的低密度区（离群点）被参考的密度压下去。
- 推广到时间序列（多时间点软约束）。
- 算法：求解 SSB 归结为从几何混合分布采样，论文给出 score matching 式算法（几何混合的 score 是两个 score 的凸组合），MNIST 上演示污染数据下的鲁棒生成。

## 实验与证据

- 理论文章，贡献清单：SSB 的解的显式刻画、几何混合定理、时间序列推广、几何混合的 score 采样算法。
- 数值：MNIST 加离群污染，SSB 生成的样本比硬约束 SB 更少受污染影响。规模小，只做概念验证。

## 与 SB×RL 的关联

几何混合定理直接翻译成 RL 语言：如果把「目标分布」取为 Boltzmann 策略 $\propto\exp(Q/\alpha)$、参考取为当前策略的路径终端，SSB 的解就是 $\pi_{\text{new}}\propto\pi_{\text{old}}^{\,a}\exp(Q/\alpha)^{\,b}$——恰好是 MDPO/AWR 一族「KL 正则策略改进」的闭式解形式。也就是说，**mirror descent 的策略更新在路径空间的严格版本就是一个 SSB 问题**，GSB-MDPO 隐含地在解它。这给了 path-space RL 一个比「上界引理」更强的工具：不只知道路径 KL 控制终端 KL，还知道最优终端分布的**精确形式**。对 SB 策略的鲁棒性也有含义：示范数据含坏样本时，SSB 的几何混合天然压低离群模式，是「多模态保持 vs 坏模式过滤」权衡的原则性旋钮。

## 局限与批判

- 纯理论 + 小规模数值，没有可扩展算法（几何混合的 score 采样在高维未验证）。
- $\beta$ 的选择没有指导，鲁棒性与保真度的权衡靠人拍。
- 只处理终端软约束，路径中间费用（GSB 的 $V_t$）不在框架内。
- 与 RL 的联系是本解读的推论，论文本身完全不涉及控制/策略应用。
