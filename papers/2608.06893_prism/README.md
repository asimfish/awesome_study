# PRISM: Principled Reference Identification for Schrödinger Bridge Models

> Fallah, Yang (Arizona State), arXiv 2026-08。[arXiv:2608.06893](https://arxiv.org/abs/2608.06893)

## 一句话

第一份关于「桥的参考过程该怎么选」的理论：刻画了保持精确可解的时变高斯参考族（协方差两两可交换），证明**不可见性原理**——精确漂移 + 无限步数下所有合法参考给出同一后验，参考的选择只在有限计算预算下才有意义——并在有限步预算下给出闭式最优噪声谱：正比于「传感器摧毁的信息谱」$P_k$。把参考设计从超参搜索变成一次计算。

## 问题与动机

I2SB 一系的桥模型沿参考过程的条件桥训练，参考几乎总是手拍的白噪声 + 标量调度，被当成实现细节。图像扩散领域已有零散实证说噪声「颜色」（频谱分布）有影响，但没有测量算子的单端生成设定里无法推导偏好谱，只能搜。桥的设定有退化算子 $h$——恰好提供了「哪些频率被摧毁」的信息，PRISM 追问：这能不能变成一个可证明的参考设计规则？

## 方法核心

1. **Theorem 1（可交换参考的可解性）**：参考 $dX_t=L(t)dB_t$，$Q(t)=LL^\top$。I2SB 类方法要的两个闭式对象（条件桥的均值/方差、逐模态调度）存在 $\iff$ $Q(s)Q(t)=Q(t)Q(s)$ $\iff$ 存在时间无关正交基 $U$ 使 $Q(t)=U\,\text{diag}(q_k(t))U^\top$ $\iff$ 在 $Y=U^\top X$ 坐标下参考是独立的时间变换标量布朗运动。Corollary：每个模态由「颜色」$v_k$（总方差）与「分配」$\rho_k(t)$（单调调度）完全参数化，$q_k=v_k\dot\rho_k$。静态有色参考 $Q=\beta(t)\Sigma$ 是所有模态共享一个 $\rho$ 的严格子族。
2. **可解模型 + 不可见性原理**：逐模态高斯退化 $x_1=hx_0+n$，后验 $x_0|x_1\sim\mathcal{N}(Wx_1,P)$（Wiener 增益 $W$，后验方差 $P$）。定理：只要漂移精确、求解步数无限，**任何**可交换参考都恢复真后验——参考对极限解不可见。
3. **有限步理论**：$T$ 步终端律闭式可得；逐模态 KL 只通过 $x=v/P$ 依赖参考，故一切最优解满足 $v_k=x^*P_k$（噪声谱 $\propto$ 被摧毁信息谱），均匀网格上 $x^*(T)=(2\ln T)^{-1/2}(1+o(1))$，最优 KL 为 $\frac{\ln T}{2T^2}(1+o(1))$。**z-恒等式**：颜色与调度可互换——逐模态调度下离散化误差对颜色盲，最优调度唯一且有 $4P/T$ 下限；聚簇网格上颜色目标多局部极小，二者不能独立设计。正则化可证地把最优参考推向白噪声。

## 实验与证据

- 高斯设定：预测的参考排序与闭式损失下限全部被数值实验确认。
- FFHQ 真实图像：失真-感知权衡与谱局部化现象迁移成立，但**白噪声反而优于「匹配参考」**——预注册实验排除了岭白化的解释，2×2 机制研究把反转归因于真实图像逐模态的非高斯统计。论文诚实地标出了理论失效的精确位置。
- 评价：理论部分完整自洽；实证部分「理论在真实图像上被推翻」是少见的负结果诚实汇报，也是它最有信息量的部分。

## 与 SB×RL 的关联

不可见性原理对 SB 策略是一个双刃论断：(1) 它宣告「换参考过程」在多步极限下毫无意义——FLAC 用高熵参考、GSB 用布朗参考、informative reference 的种种设想，其差别只在**有限步**下存在。这正好把 SB 的差异化钉死在 few-step/one-step 区间：参考设计只在这里有价值，而这恰是机器人控制所在的区间。(2) 有限步最优谱 $\propto$ 被摧毁信息谱，翻译到策略语言：参考过程的噪声应该集中在「观测无法决定的动作维度」上——这给 informative source 策略（BridgePolicy/RSBM）的先验设计提供了第一条可计算的规则，也给「$\epsilon$ 该取多大」提供了 $x^*(T)$ 这样的量级参考。同时它的 FFHQ 反转警告：动作分布同样非高斯，理论规则要在实验里校准。

## 局限与批判

- 全部理论在高斯逐模态模型内，真实数据（FFHQ）上核心预测被推翻，适用范围要打折。
- 只讨论 I2SB 类 paired 桥（有退化算子 $h$），unpaired SB（DSBM/SB Flow）与带路径费用的 GSB 不在框架内。
- 「传感器摧毁的信息谱」在策略学习里没有直接对应物，翻译到 RL 需要额外建模。
- 数值实验规模小，无大模型验证。
