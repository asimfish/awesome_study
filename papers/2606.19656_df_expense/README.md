# DF-ExpEnse: Diffusion Filtered Exploration for Sample Efficient Finetuning

> Luo, Sun, Song (Stanford & Brown), arXiv 2026-06。[arXiv:2606.19656](https://arxiv.org/abs/2606.19656)

## 一句话

用预训练扩散策略的多模态采样把连续动作空间「过滤」成一组可信候选，再用 critic 集成的 UCB（价值 + 不确定性）挑出最有探索价值的那个去执行——只改在线数据收集这一步，DSRL/ResFiT 两种微调骨架的样本效率都涨，并给出多机器人舰队协同探索的扩展。

## 问题与动机

从预训练生成式策略出发做 RL 微调，瓶颈常不在更新算法而在数据质量：策略采一个动作就执行，探索是被动的。经典 UCB 式探索在连续动作空间上没法逐动作评估；Max-Q 选择（BFN/Q-chunking）只顾利用、不顾探索，多轮微调后策略收窄、泛化变差。

## 方法核心

1. **扩散过滤**：每步从预训练扩散策略 i.i.d. 采 $M$ 个候选 $[a_1,\dots,a_M]\sim\pi^{\text{dp}}_\theta(\cdot|s)$——多模态策略天然给出覆盖各模式的「合理动作集」，把无限连续空间压成可枚举候选。
2. **集成 UCB 选择**：critic 集成对每个候选给出均值与方差，按「价值 + 不确定性奖励」选执行动作——探索兴趣显式进入选择，而不是 Max-Q。
3. **BC 采样正则（BC-SR）**：多轮微调后策略会收窄到少数模式；用初始 BC 策略采 $p\le M$ 个候选混进候选集，防止探索多样性随微调坍缩。
4. **舰队扩展**：$N$ 个并行机器人各采 $M$ 候选，实时共享 critic 集成的统计量，在 $N\times M$ 的联合候选集上做集体 UCB，避免舰队成员重复探索同类轨迹。
5. 只改「收集」不改「更新」：与 DSRL（latent 噪声 SAC）、ResFiT（残差微调）零改动组合，性能增益可完全归因于数据质量。

## 实验与证据

- 在 DSRL 与 ResFiT 两种骨架上，同等数据量下微调样本效率一致优于 vanilla 与 Max-Q 选择基线；舰队设定下集体探索进一步加速。
- 评价：控制变量做得干净（只动收集步）；但绝对数字与任务面在检索到的文本里不够突出，属于「稳健的增量改进」而非范式变化。

## 与 SB×RL 的关联

DF-ExpEnse 与 MVP 一起把「生成 N 个候选、按 critic 选」推成了绕开 log π 的第五条实用路线（选择即策略改进/探索）。它对 SB 侧的直接价值：**候选集的质量取决于生成策略的模式覆盖**——这正是 SB 的 $\epsilon$ 旋钮能控制的量。用 $\epsilon$ 谱系生成候选集（$\epsilon$ 大 → 覆盖广、探索型；$\epsilon$ 小 → 集中、利用型）比 i.i.d. 高斯噪声重采样更有结构，且不需要 BC-SR 这样的补丁来防坍缩。这是一个可以直接在 DF-ExpEnse 框架里做的对照实验。

## 局限与批判

- 推理成本 $M$ 倍（加集成 critic 的评估），实时控制预算下 $M$ 受限，与「一步化」的速度诉求相悖。
- BC-SR 是经验补丁，模式坍缩的根因（微调目标本身）没有被处理。
- 舰队协同依赖实时低延迟通信与同构任务，真实舰队的异构性未考虑。
- 增益幅度属渐进改进；无真机在线微调证据（检索文本范围内）。
