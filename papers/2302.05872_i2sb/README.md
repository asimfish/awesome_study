# I2SB: Image-to-Image Schrödinger Bridge

> Liu, Vahdat, Huang, Theodorou, Nie, Anandkumar (NVIDIA & GaTech), ICML 2023。[arXiv:2302.05872](https://arxiv.org/abs/2302.05872)

## 一句话

发现 paired 数据下 SB 有免迭代的可解形式：把退化图像当作桥的边界而非条件，图像修复类任务用 10-20 步就超过条件扩散基线——informative source 价值的第一个大规模实证。

## 问题与动机

条件扩散做图像修复的别扭之处：生成从纯噪声出发，退化图像（低分辨率图、遮挡图）只能作为条件信息注入网络——起点的结构信息被浪费，路径被拉长。SB 的语言恰好对症：让退化图像成为桥的一端。障碍是通用 SB 求解要 IPF 迭代（贵且不稳）。I2SB 的观察：图像修复天然是 paired 数据（干净图与其退化版成对），这个特殊结构让 SB 塌缩成可解形式。

## 方法核心

当边界耦合取「成对数据」（$x_0$ 干净图、$x_1 = $ 其退化版）时，两点间的最优桥就是参考过程的布朗桥，其后验有 DDPM 式的解析高斯形式：

$$
p(x_t\mid x_0, x_1) = \mathcal{N}\big(\mu_t(x_0, x_1),\ \Sigma_t\big),\quad \mu_t = \frac{\bar\sigma_t^2}{\bar\sigma_t^2+\sigma_t^2}x_0 + \frac{\sigma_t^2}{\bar\sigma_t^2+\sigma_t^2}x_1
$$

- $\sigma_t^2, \bar\sigma_t^2$：从两端累积的噪声方差。训练就是在这条解析桥上采样 $x_t$、回归指向 $x_0$ 的漂移——与 DDPM 训练同构，只是「起点」从高斯换成退化图像，**不需要 IPF 迭代**。
- 采样从退化图像出发沿学到的漂移走向干净图，无噪声极限下退化为 OT-ODE——步数可以压得很低且行为可解释。
- 网络直接复用预训练扩散模型的架构与权重初始化。

## 实验与证据

- ImageNet 256×256 四类修复任务（4x 超分、去模糊、inpainting、JPEG 修复）：全面优于 Palette、DDRM、ΠGDM 等条件扩散/后验采样基线。
- 关键效率证据：多数任务 NFE≈10-20 即达最优质量，条件扩散基线需要 100-1000——起点带信息则路径短，路径短则少步稳。
- 消融：同架构同算力下，唯一变量是「退化图当边界 vs 当条件」，证明收益来自问题表述而非工程。

## 与 SB×RL 的关联

I2SB 是「informative source 红利」的定量锚点：起点有结构 → 桥短 → 少步稳，这条逻辑链在图像上拿到了硬数字。机器人侧的同构场景现成：上一个 action chunk → 下一个 action chunk（时序连续性=结构）、粗规划 → 精细动作、sim 轨迹 → real 轨迹。其中「上一 chunk 当桥起点」的策略架构（替代每步从纯噪声重新去噪）在 2026-09 仍无正式占位，是 06 类最直接的可开采空格。约束也要认清：I2SB 的免迭代解依赖 paired 边界，RL 场景的「当前策略分布→最优策略分布」是 unpaired 的，得回到 DSBM/GSBM 的机制。

## 局限与批判

- 只适用 paired 边界：耦合被数据锁死，学到的不是真 SB（最优耦合），而是「给定耦合下的最优桥」——论文对此诚实但容易被误读。
- 确定性退化（如固定下采样核）下表现最好，真实世界的未知退化分布外泛化没有验证。
- 多样性-保真度权衡由噪声尺度手工控制，多模态输出的评测缺失。
