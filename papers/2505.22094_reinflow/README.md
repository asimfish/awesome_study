# ReinFlow: Fine-tuning Flow Matching Policy with Online Reinforcement Learning

> Zhang et al., NeurIPS 2025。[arXiv:2505.22094](https://arxiv.org/abs/2505.22094)

## 一句话

给流策略的确定性路径注入**可学习**噪声，把流变成离散时间马尔可夫过程从而有精确逐步似然，PPO 直接可用；Rectified Flow 与 Shortcut 策略在极少步（甚至一步）下稳定微调——腿式运动回报净增 135.36%、比 DPPO 省 82.63% 墙钟；操纵成功率净增 40.34%（4 步或 1 步）。DPPO 的 flow 对位物。

## 问题与动机

DPPO 证明了扩散策略可以在线 PPO 微调，但扩散策略步数多、微调慢；流策略步数少却是确定性 ODE，没有似然与随机性。ReinFlow 要在流上复现 DPPO 的范式，并把「少步」的优势带进微调阶段。

## 方法核心

1. **注入可学噪声**：每个积分步 $x_{k+1}=x_k+\Delta t\,v_\theta(x_k,t_k,s)+\sigma_\phi(x_k,t_k,s)\,\epsilon$——噪声标准差 $\sigma_\phi$ 由网络输出并参与训练（与 [Flow-GRPO](../2505.05470_flow_grpo/) 固定噪声调度的 ODE→SDE 不同，这里探索强度是学出来的、状态相关的）。路径变成离散时间马尔可夫链，联合似然 $\log\pi(x_{0:K}|s)=\sum_k\log\mathcal{N}(x_{k+1}|\mu_k,\sigma_k^2)$ 闭式、精确。
2. **PPO 在链上**：与 DPPO 同构的两层 MDP，clip + GAE + 熵/噪声正则；理论上从 RL 基本定理推导注噪后的策略梯度无偏性。
3. **少步友好**：因为似然对步数没有要求，可以在 4 步甚至 1 步下微调 Rectified Flow / Shortcut 策略——这是相对 DPPO（需要足够长的去噪链做探索）的结构优势。

## 实验与证据

- 腿式运动（长程、稀疏奖励）：Rectified Flow 策略微调后平均回报净增 135.36%，相对 DPPO 省 82.63% 墙钟时间且去噪步更少。
- 状态/视觉操纵：Shortcut 策略在 4 步或 1 步微调后成功率净增 40.34%，与微调后的 DDIM 策略相当，省 23.20% 计算。
- 评价：对 DPPO 的墙钟对比有说服力；「1 步微调」的成功率在最难任务上仍略低于多步，一步 RL 的稳定性问题没有完全解决（[DMPO](../2601.20701_dmpo/)/[DBPO](../2604.03540_dbpo/) 后续专攻此点）。

## 与 SB×RL 的关联

ReinFlow 的「可学噪声 $\sigma_\phi$」是一个被忽视的 SB 接口：状态相关、可学的扩散系数正是 SB 里控制熵正则强度的量——ReinFlow 实际上在学一个状态相关的 $\epsilon(s)$，只是没有用这个语言。把它与 [RSBM](../2604.05673_rsbm/) 的 $\epsilon$ 谱系对接：$\epsilon$ 不再是全局超参，而是策略按状态决定「这里需要多少随机性/多模态」的输出——探索与多模态保持在同一个可学变量里统一了。这是 SB 策略 RL 微调时最自然、也尚无文献的设计：让桥的熵正则强度成为策略的一部分，由 RL 目标驱动。

## 局限与批判

- 注噪改变了策略的边际分布（不像 Flow-GRPO 保边际），微调起点与预训练策略有偏差，需要 BC 正则或小 $\sigma$ 初始化兜底。
- 逐步似然连乘的方差随步数增长（一步时最小，这也是它一步表现好的原因之一），多步长链下与 DPPO 同样受高方差困扰。
- 「135.36%」等相对增幅来自低起点的 BC 策略，绝对性能对比不够透明。
- 无真机。
