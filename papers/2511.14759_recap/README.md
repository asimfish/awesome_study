# π*0.6: a VLA That Learns From Experience (RECAP)

> Physical Intelligence, arXiv 2025-11。[arXiv:2511.14759](https://arxiv.org/abs/2511.14759)

## 一句话

用「优势条件化」把 VLA 的 RL 变成条件监督：训一个多任务价值函数给动作打优势分、二值化成 positive/negative 指示 token 放进 VLA 前缀、推理时永远条件 positive——免策略梯度、免似然、吃下示范/自主 rollout/人工纠正三种数据，真实家庭叠衣、装箱、做咖啡吞吐翻倍、失败率减半。工业界对 log π 障碍的正式答案。

## 问题与动机

BC 预训练的 VLA 成功率能到一半，但要「每次都成、吞吐接近人类」，必须从自身经验中改进。PPO/REINFORCE 对流匹配动作头的 VLA 不友好（似然不可算、on-policy 样本贵、大模型训练不稳），且它们不能自然吃下异构数据（示范 + 自主 rollout + 专家纠正）。RECAP 要一个对大模型、对流动作头、对混合数据都友好的策略提取方法。

## 方法核心

三步迭代（偏 offline RL 的 iterated 版本）：

1. **数据收集**：部署当前策略，收自主 rollout + 人类干预纠正 + 回合成败标注。
2. **价值函数**：全部数据训一个语言条件的分布式价值函数 $V^{\pi_{\text{ref}}}(o)$，估计到任务完成的期望时间、检测失败。优势为 $N$ 步回报 + 自举减去当前价值：$A(o_t,a_t) = \sum_{t'=t}^{t+N-1} r_{t'} + V(o_{t+N}) - V(o_t)$。
3. **优势条件化训练**：按分位数（约 30% 为 positive）把优势二值化成指示 $I_t$，作为文本 token 放进 VLA 前缀训练；训练时对指示做 dropout（约 30%），推理时固定输入 positive。理论依据：$\hat\pi(a|o)\propto\pi_{\text{ref}}(a|o)\,p(I|A^{\pi_{\text{ref}}}(o,a))^\beta$——条件化等价于对参考策略按「动作好的概率」做指数重加权，是带 KL 约束的策略改进的另一种实现（与 AWR 的 $\exp(A/\lambda)$ 加权同源，只是权重进了输入而非 loss）。

关键性质：**所有数据都参与训练**（坏动作标 negative 而非丢弃），大模型在「多数据 + 标注」下泛化最好；不需要 $\log\pi$，不需要 on-policy 采样。

## 实验与证据

- 真实任务：家庭叠衣、纸箱装配、专业咖啡机做饮品——最难任务吞吐提升约 2 倍、失败率减半，咖啡机连续运行整天。
- 对比：纯 BC 预训练 → +offline RL 预训练（π*0.6）→ +在线经验与纠正（完整 RECAP）逐级提升。
- 评价：真实部署级证据是学术界基线做不到的；但没有与 PPO/DPPO 类方法的受控对比（论文明确说是避开它们），「优势条件化 vs 策略梯度」的优劣在同等数据下并未被检验。

## 与 SB×RL 的关联

RECAP 和 path-space 路线从相反方向抵达同一结论——不要碰生成式策略的终端似然。RECAP 的代价是理论上限：它只能把策略推向数据里已有的最好行为（重加权 $\pi_{\text{ref}}$，支撑集不变），没有真正的策略梯度式外推。SB 视角能给它一个精确的定位：优势条件化 = 用 $\exp(\beta\cdot\text{good})$ 对参考测度做 Feynman-Kac 式重加权后做投影，这正是 GSB 的软终端势 $\mathcal{G}$。于是「RECAP + 路径正则」有明确含义：在重加权之外再给生成路径加动能约束，可以在不算似然的前提下让策略**离开**参考支撑集（受控探索）——这是工业界配方与 SB 理论最自然的接口，目前无人做。

## 局限与批判

- 天花板明确：好不过数据里最好的行为；论文自己承认 RECAP 找不到全局最优。
- 二值化阈值（30% 分位）与指示 dropout 率是拍出来的，敏感性无公开分析。
- 依赖高质量价值函数——分布式价值函数在长程稀疏任务上的可靠性是全部方法的单点故障。
- 闭源模型与数据，可复现性为零；作为方法论参考价值高，作为基线无法使用。
