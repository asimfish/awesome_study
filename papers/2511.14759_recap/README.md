# π*0.6: a VLA That Learns From Experience (RECAP)

> Physical Intelligence, arXiv 2025-11。[arXiv:2511.14759](https://arxiv.org/abs/2511.14759)

## 一句话

RECAP 用价值函数生成“好动作”条件标签，把示范、自主经验和人工纠正纳入同一套 VLA 训练，在困难叠衣与浓缩咖啡任务上使成功吞吐翻倍，给流匹配策略提供了绕开连续动作精确似然的实用 RL 配方。

## 问题与动机

示范能教会机器人完成任务，却未必覆盖它部署时反复犯的错误，也不保证动作足够快。RECAP 要同时改善成功率与完成速度，并利用不同来源、不同质量的数据，而不是每轮只训练最新策略采到的轨迹。

流匹配动作头难以直接提供精确动作似然，这让常见策略梯度实现更复杂；用优势加权回归又会大幅压低部分数据的训练权重。作者转而把优势作为输入条件，保留负面经验的监督信号，部署时选择有利条件。算法属于反复收集数据、再进行离线更新的 RL，既能利用旧数据，也实际依赖当前策略部署来获取新经验。

## 方法核心

**价值函数评价速度与成败。** RECAP 全称为 *RL with Experience and Corrections via Advantage-conditioned Policies*。语言条件的分布型价值函数把经验回报离散为 201 档，以交叉熵训练，再用分布均值估计价值；这不是分布式训练。奖励在非终止步为 −1，成功终止为 0，失败终止施加较大负惩罚，并按任务最长时限归一化。它学习数据混合行为的价值，不是对任意候选动作求最大值的 Q 函数。

后训练采用同轨迹未来 $N=50$ 步构造优势估计：

$$
\hat A_t=\sum_{t'=t}^{t+N-1}r_{t'}+V(o_{t+N},\ell)-V(o_t,\ell),
$$

其中 $\ell$ 为任务语言条件，$V$ 由完整经验回报监督，公式中的自举用于估计优势，两者不能混称为 TD 价值训练。

**二值优势进入动作条件。** 指示 $I_t=\mathbf1[\hat A_t>\epsilon_\ell]$ 以文本形式放在预测子任务之后、动作之前，因此直接条件化的是动作输出。按附录 F，预训练约 30% 示范标正，微调通常约 40%，T 恤和短裤任务约 10%；人工纠正强制标正。训练以 30% 概率删除指示，联合学习有条件与无条件策略，部署默认使用正指示。

**策略提取沿用监督目标。** 离散输出仍用交叉熵，连续动作使用流匹配损失，因此准确说法是不需要连续动作的精确似然，而非完全“不用似然”。式（2）把改进策略写成参考策略与条件／无条件密度比幂的乘积；默认 $\beta=1$ 时就是正条件策略，较强 CFG 可进一步锐化分布。理想策略的改进性质不能直接替代对近似价值、二值标签和有限数据训练的检验。

**每轮聚合经验并重新拟合。** 新增自主轨迹和可选人工纠正后，价值与策略都从各自预训练检查点重新微调，避免沿上一轮模型持续漂移。负标签动作参与条件监督，不等于部署时主动选择坏动作；持续收集新轨迹也使该方法不受最初示范集合固定限制。

## 实验与证据

- **主结果，图 7、8。** 从“离线 RL 预训练＋任务示范微调”到完整 RECAP，困难的多样衣物折叠与浓缩咖啡任务成功吞吐超过两倍，失败率约减半；吞吐是每小时成功完成次数，综合速度与成功率，不能泛化为所有任务均翻倍。
- **多轮改进，图 9、10。** T 恤和短裤折叠只用自主收集数据，两轮带来约 50% 吞吐提升；装箱结合自主经验与纠正，两轮后吞吐约翻倍，但第一轮吞吐先下降，实际训练没有逐轮单调改进保证。
- **策略提取对照，图 11及附录 D。** 在同一批折叠任务数据上，RECAP 的吞吐优于 AWR 和 PPO 变体；后者使用 DPPO/FPO 式单步扩散似然代理及 SPO 约束，因离策略更新需收紧信赖域。这是真实存在的受控数据比较，但不是标准在线 PPO 的公平上限测试。
- **持续部署。** 原文报告连续制作咖啡 13 小时，以及在新家庭连续折叠新衣物超过两小时；这是运行持续性证据，不能改写成无人参与、零失败的整日自治。

## 在谱系中的位置

[AWR](../1910.00177_awr/) 把优势放进样本权重，RECAP 把二值优势放进条件输入；二者都属于价值引导的策略提取。更直接的上游是 CFGRL，即原文引用的 *Diffusion guidance is a controllable policy improvement operator*，其条件化与 CFG 解释比泛称“源于 Decision Transformer”更准确。

与 [DPPO](../2409.00588_dppo/) 的差异在于训练接口：RECAP 沿用监督训练并改变条件，后者通过生成过程的策略优化利用奖励。它的强项是把异构数据、价值估计和大规模 VLA 训练串成可部署系统；“工业界对似然问题的唯一答案”没有依据。

## 与 SB×RL 的关联

RECAP 给 SB 策略提供了可直接比较的奖励接口：固定预训练策略、示范与在线交互预算，用同一价值函数生成优势标签，比较普通流动作头与桥式动作头在正条件训练后的成功吞吐、动作偏移和模式覆盖。这样可以检验桥结构是否改善奖励条件化，而不会把价值函数或人工纠正差异误算成桥的贡献。另一项实验是在采集阶段对桥的随机性做受控扫描，匹配纠正次数，观察能否发现新的成功行为并被下一轮训练吸收。单次理想重加权受参考分布支撑限制，反复收集经验却能改变数据分布；不能据此前者断言 RECAP 永远超不过示范，也不能宣称加上路径动能正则就自动获得支撑外探索。探索收益必须来自实际新增的有效轨迹。

## 局限与批判

- 价值函数拟合混合行为的经验回报，若把缓慢但安全的恢复误判为低优势，条件训练会系统性压低这些动作，论文未给出误差传播控制。
- 人工纠正一律标正，而正文承认纠正质量并不一致，二值标签可能把操作者偏差固化为策略改进方向。
- 数据采集仍依赖人工成败标注、干预和回合重置，报告的任务吞吐没有折算这些人力成本。
- PPO 对照只覆盖折叠任务的离策略提取设置，不能推出优势条件化普遍优于在线策略梯度。
- 失败模式消除实验在正文称无纠正数据，附录 F 却列出该实验的纠正回合，97% 成功率对应的数据构成无法仅凭原文统一确认。
