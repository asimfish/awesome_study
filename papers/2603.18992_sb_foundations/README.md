# Foundations of Schrödinger Bridges for Generative Modeling

> Tang (UPenn), arXiv 2026（215 页教程式综述）。[arXiv:2603.18992](https://arxiv.org/abs/2603.18992)

## 一句话

一部从第一性原理出发的 SB 教科书：以「对参考过程的最小熵偏离」为唯一主线，把静态/动态 SB、随机最优控制、全部主流构造工具与现代算法（DSBM/SF2M/Adjoint Matching）系统性地串成一个自洽框架。

## 问题与动机

SB 文献碎片化严重：同一个对象在 OT、随机分析、控制论、生成建模四个社区各有一套记号与表述，方法之间的等价关系（IPF vs IMF、h-变换 vs FBSDE、静态 vs 动态）散落各处。这份指南的目标是给出统一的数学地基，让读者能从原理出发推出（而非背下）每个现代算法。

## 方法核心

九章的逻辑链条（对读者最有用的是这个骨架本身）：

1. **静态 SB**（§1）：Monge/Kantorovich OT → 熵正则 OT → 静态 SB → Sinkhorn 算法；
2. **动态 SB**（§2）：路径测度与 Itô 过程、Fokker-Planck 与 Feynman-Kac、**Girsanov 定理**（路径 KL = drift 的 L2 能量——本仓库 RL 侧反复用的恒等式在 §2.5-2.6 有完整推导）、任意参考动力学、Hopf-Cole 变换、SB = 熵正则动态 OT；
3. **SB 即随机最优控制**（§3）：SOC 表述与各种可训练目标；
4. **构造工具箱**（§4）：条件桥混合、时间反演、FBSDE、Doob h-变换、Markov/reciprocal 投影、随机插值→SB——五种主流构造的等价与差异一次说清；
5. **变体**（§5）：高斯 SB（闭式解）、**广义 SB**、多边际、不平衡、分支、分数阶——问题空间的地图；
6. **生成建模算法**（§6）：score 生成入门、FBSDE 似然训练、DSBM、SF2M、Adjoint Matching；
7. **离散状态空间**（§7）：CTMC 上的 SB、离散 DSBM——语言/图结构生成的接口；
8. **应用**（§8）：数据翻译、单细胞动力学、Boltzmann 采样。

没有新定理主张，价值在于统一记号下的完整推导与方法间关系的显式化。

## 实验与证据

教程综述，无实验。作为参考书的证据：约 11 万词、9 章、覆盖 2021-2026 的主流 SB 算法，每章附闭式推导。

## 与 SB×RL 的关联

对 SB×RL 研究者这是最高效的军火库：(1) §2.5-2.6 的 Girsanov 与路径 KL 推导是 FLAC 动能正则、GSB-MDPO 路径邻近项的共同数学来源，引用时指这里比指原始概率论文献友好得多；(2) §3 的 SOC 目标清单（cross-entropy、log-variance、moment matching 等）是设计 SB 策略训练 loss 的现成菜单；(3) §5 的变体地图提示了未开采方向——多边际 SB 对应多阶段任务规划、不平衡 SB 对应带终止的回合结构，都还没有 RL 侧的文献。注意它完全不覆盖 RL/控制回路中的 SB（FLAC/GSB-MDPO 晚于或平行于它），这个空白恰好是本仓库 06 类的位置。

## 局限与批判

- 教学导向，工程细节（训练稳定性、超参敏感性、规模化瓶颈）基本不碰——读完会推导不等于能训出来。
- 单作者长文，部分前沿定性（如少步采样各路线的优劣）没有实验依据，属作者观点。
- 不含 RL/具身应用，本仓库读者需自行完成从 §5.2（GSB）到策略优化的最后一公里。
