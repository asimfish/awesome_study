# Mean Flow Policy with Instantaneous Velocity Constraint for One-step Action Generation (MVP)

> ICLR 2026 (Oral, top 1%)。[arXiv:2602.13810](https://arxiv.org/abs/2602.13810)

## 一句话

MVP 用瞬时速度约束与 Q 值筛选稳住一步控制，平均在线训练每秒153.6次迭代，成功率则接近最强多步基线，把竞争焦点落在省去教师的训练结构与可靠的价值选择，生成器更快须兑现为更好的控制。

## 问题与动机

多步流策略能拟合复杂动作分布，却要为每次环境交互反复计算速度场；将积分步数直接压到一步，会损失长程任务表现。MeanFlow 学习整个时间区间的平均速度，提供直接从噪声到动作的映射，但还要解决策略改进和回归稳定性两个问题。

MVP 把这两个问题拆开：生成器负责拟合动作，Q 函数负责从候选中选优。平均速度训练则显式补上零长度区间的瞬时速度条件，避免只约束区间内部、忽略边界。它是生成策略与价值筛选的组合，不是通过 Q 梯度直接优化动作生成网络。

## 方法核心

**一步生成、候选筛选。** 给定状态 $s$，从高斯采样 $\epsilon_i$，按原文式（11）生成 $a_i=\epsilon_i+u_\theta(\epsilon_i,0,1,s)$，再选择 Q 值最高的动作。这里 $u_\theta(a(t),t,r,s)$ 表示区间 $[t,r]$ 的平均速度，本文采用 $t<r$、从噪声走向动作的时间方向。“生成＋选择”共同构成执行策略；所选动作也用于自举训练，critic 按 TD 目标更新，Q 梯度不穿过生成器。

**平均速度恒等式与边界。** 对线性插值 $a(t)=(1-t)a(0)+ta^*$，训练路径速度为 $v=a^*-a(0)$，平均速度目标满足

$$u=v-(t-r)\frac{d u}{dt}.$$

全导数包含沿动作方向和时间方向的变化，通过 JVP 计算；目标中的导数项停止梯度，不能误读成普通速度回归。Theorem 2 指出：仅在开区间完美满足恒等式，误差仍可写成 $\Delta_u=C(a,r)/(r-t)$，区间内部的方程没有独立钉住边界。

IVC 显式训练对角线 $t=r$：

$$\mathcal L_{\mathrm{IVC}}=\mathbb E\|u_\theta(a(t),t,t,s)-v\|^2,\qquad
\mathcal L_{\mathrm{policy}}=\mathcal L_{\mathrm{MF}}+\lambda\mathcal L_{\mathrm{IVC}}.$$

Theorem 3 将该条件用于理想场的唯一性论证；它不等于有限样本、有限损失下的误差保证。默认 $\lambda=1$，方法同时采用 action chunking，不能把整体收益全归给 IVC。

**策略改进界。** Theorem 1 把性能差下界分成非负的 best-of-N 优势和 critic、动作拟合误差的惩罚；优势不足以覆盖误差时，下界仍可为负。它说明准确拟合为何有用，没有保证每次实际更新都提高回报。

## 实验与证据

- 表 1 覆盖 Robomimic 的 lift/can/square 与 OGBench 的六个 cube-double/triple 任务，五个种子的均值±标准差为 MVP $0.88\pm0.05$、QC $0.86\pm0.05$、BFN $0.52\pm0.06$、FQL $0.44\pm0.05$；MVP 对 QC 的平均优势很小，不能写成压倒性胜出。
- Cube-triple-task4 上 MVP 为 $0.52\pm0.11$、QC 为 $0.46\pm0.13$；后者是单任务成绩，不是 QC 的总平均。图 4 的 IVC 消融中，该任务从无 IVC 的 $0.30\pm0.21$ 升至完整版本的 $0.52\pm0.11$，支持这一约束有实际作用。
- 图 5 只在 cube-triple-task3/4 比较朴素一步基线，两项任务的成功率接近零；结论应限定为这些长程任务，不能扩大为所有一步流策略都失效。
- 表 2 的平均在线训练速度为 MVP $153.6\pm11.5$ iter/s、QC $92.6\pm6.3$ iter/s；表 3 中 MVP 推理 $10.93\pm0.95$ ms，与 FQL 的 $10.76\pm1.02$ ms 相近，明显快于 BFN/QC。

训练从离线数据启动，再收集在线交互：Robomimic 使用多操作者示范，OGBench 使用默认 play 数据；表 6 的离线和在线训练各为一百万步，因此这些成绩不能读成纯离线学习或零示范探索的表现。

推理计时使用 AMD Ryzen Threadripper 3960X CPU，并关闭 JAX JIT；这个协议不能直接预测编译后 GPU 部署的差距。表 6 报告 Robomimic 使用 16 个候选、OGBench 使用 32 个候选；候选可批量生成，“一步”指每个候选的一次生成映射，并非只评估一个动作，也不意味着墙钟耗时严格乘以候选数。

## 在谱系中的位置

MVP 继承 [MeanFlow](../2505.13447_meanflow/) 的平均速度表示，将它接入 best-of-N 和 Q-chunking 的价值筛选路线；IVC 是其有区分度的训练改动。[FQL](../2502.02538_fql/) 在本文基准上成功率落后，但其蒸馏策略已经实现相近的单次推理速度，MVP 的优势还包括少维护一套多步教师的训练成本。这个对照把表示能力与训练结构分开：更快的生成器只有配合可靠的价值选择，才会变成更好的在线控制策略。

它与 [MP1](../2507.10543_mp1/) 的模仿学习、[DMPO](../2601.20701_dmpo/) 的策略梯度路线应分开读：MVP 的策略改进压力来自候选选择，且与动作 chunking 绑定；本文没有直接比较这些方法，不能据此排出统一名次。

## 与 SB×RL 的关联

最直接的实验是固定同一 critic、离线数据和动作块长度，仅替换候选生成器：比较高斯起点的 MVP 与桥式候选生成器，在相同候选数和相同墙钟预算下记录成功率、动作模式覆盖及 Q 误选率，检查结构化起点能否减少筛选需求；必须保留无筛选版本，分清生成质量与 critic 选择的贡献，并在不同候选预算下重复比较，避免只选择桥模型最有利的配置。

另一个切口是给压缩后的确定性桥流加入对角线速度约束，比较有无该项时的边界速度误差和一步动作误差。MVP 的定理针对确定性平均速度恒等式，不能直接套到含噪声的 SB 路径；桥的条件漂移如何构造监督需要单独验证。两项实验分别检验候选预算与压缩误差，不应把 best-of-N 写成免费策略改进，也不能预设桥起点一定提高多样性。

## 局限与批判

- 对最强 QC 基线的平均成功率提升小于所报波动，证据更支持效率改进，不能据此宣称稳定的性能领先。
- 16/32 个候选和 Q 筛选仍占计算与内存，原文没有给出候选数对成功率和部署延迟的完整权衡曲线。
- best-of-N 会放大 critic 的选择偏差，理论误差惩罚并未给出训练中可检验的安全阈值。
- 唯一性论证依赖理想恒等式与边界行为，IVC 的有限训练误差如何传导到动作误差没有定量结论。
- JVP 增加训练显存，机器人证据限于仿真，CPU 关闭 JIT 的计时也不足以证明真机闭环优势。
