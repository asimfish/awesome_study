# Bridging Dynamics Gaps via Diffusion Schrödinger Bridge for Cross-Domain Reinforcement Learning (BDGxRL)

> Hanping Zhang, Yuhong Guo（Carleton University），arXiv 预印本，2026-02-27。[arXiv:2602.23737](https://arxiv.org/abs/2602.23737)

## 一句话

BDGxRL 用 DSB 把可交互源域的转移改写成目标域风格，再重估奖励供 SAC 学习，将无奖励目标示范从模仿素材变成了修正训练动力学的依据。

## 问题与动机

两域共享状态与动作空间，转移动力学不同；源域可交互且有奖励，目标域训练时只提供无奖励的离线状态、动作、下一状态数据。目标是在源域训练策略，再交给目标动力学执行。这里不要求源、目标转移一一配对，但目标数据包含动作，并非只有视频或状态观测。

DARC、DARA 根据跨域差异修改源域奖励，xTED 已用扩散编辑轨迹。BDGxRL 的贡献是把 DSB 转移翻译、结果感知奖励与策略学习接起来，不能把“翻译数据”本身说成首创。物理执行结果变化后，直接沿用旧奖励可能失真，因此仅修正下一状态还不够。

## 方法核心

**以完整转移向量训练桥。** 第 4.1 节把输入写为 $p=[s_t;a_t;s_{t+1}]$，用源域 rollout 与目标示范学习两个方向的漂移，采用 DSBM 的 Iterative Markovian Fitting（IMF）。源域转移是有结构的生成起点，桥参考过程是布朗运动；条件布朗桥上的漂移回归替代直接求解未知分布密度。

翻译时按式（10）离散前向 SDE：

$$
p_{j+1}=p_j+v_\theta(j\Delta,p_j)\Delta+\sigma_0\sqrt\Delta\,\xi_j,\qquad \Delta=1/K,\quad \xi_j\sim\mathcal N(0,I).
$$

$K$ 是翻译步数，$\sigma_0$ 是固定扩散强度；这里的迭代时间与环境步数无关。论文随后把输出简记为 $\tilde s_{t+1}\sim\mathrm{DSB}_{S\to T}(s_t,a_t,s_{t+1})$，但没有说明整向量翻译时如何锁住前面的状态、动作坐标，因此联合转移分布对齐与固定条件下的动力学对齐之间仍有缺口。

**在翻译结果上重估奖励。** 源域样本监督训练 $R_\omega(s,s')$，损失是对真实源域奖励的均方误差；回放时使用：

$$
\tilde r_t=R_\omega(s_t,\tilde s_{t+1}),\qquad (s_t,a_t,\tilde r_t,\tilde s_{t+1})\in B.
$$

它依赖奖励能从状态转移推断、且这一关系可跨域迁移，目标域无奖励意味着这项假设无法靠目标标签校准。若相同状态变化对应不同动作成本，模型只能拟合训练分布下的平均奖励，不能恢复遗漏的信息。

**带模仿约束的 SAC。** 策略先在目标示范上做行为克隆，在线学习仍保留模仿项，式（15）为 $L_{\mathrm{total}}=L_{\mathrm{RL}}+\alpha L_{\mathrm{IL}}$；不是初始化后完全放开优化。算法 1 第 15、20 行持续扩充源域数据并周期更新桥与奖励模型，二者并未冻结。

**性能界的实际含义。** 定理 1 的两项分别是动力学近似误差 $\epsilon_m$ 与策略近似误差 $\epsilon_\pi$，没有显式奖励模型误差项；左侧又是 $V_{M_T}^{\pi^*}-V_{M_{\mathrm{DSB}}}^{\pi}$，不是两条策略在同一真实目标 MDP 中的差距。它不能直接保证部署策略接近目标最优，文中关于样本量的误差阶也未由实验验证。

## 实验与证据

- 表 1 覆盖 HalfCheetah、Walker2d，两者均测试 Medium、Medium-Replay、Medium-Expert 数据及重力、摩擦、大腿尺寸三类偏移，共 18 个设置；结果为 5 次运行的 D4RL 归一化分数，分数不是成功率。
- 第 5.1 节将修改物理参数的环境设为源域、原始 D4RL 数据设为目标域：重力改为 2 倍、摩擦为 0.25 或 0.5 倍、大腿尺寸为 2 倍；这些离散设置没有构成系统的偏移幅度扫描。
- 实际基线为 xTED 的两种组合、DARA、DARC、DARAIL、GAIL 与 D4RL 行为策略，表中没有 VGDF 或 PAR；BDGxRL 在全部表列设置的均值最高，但误差条重叠，不能把最高均值写成已验证的统计显著优势。
- Walker2d 的 Medium-Expert 摩擦设置中，BDGxRL 为 $89.5\pm5.0$，DARAIL 为 $85.4\pm9.8$；表 3 的完整消融为 3 次运行，移除对齐的损失最大，模仿和奖励调制也有收益。

示范质量已有分层比较，不能批评为“完全没做质量消融”；示范数量、翻译步数与总训练墙钟的系统权衡则未报告。全部结果来自低维状态仿真，没有真实机器人或视觉域迁移验证。

## 在谱系中的位置

[DSB](../2106.01357_dsb/) 提供路径分布翻译框架，实际训练骨架采用 [DSBM](../2303.16852_dsbm/) 与 IMF，[SAC](../1801.01290_sac/) 负责策略优化。桥改变训练样本，策略自身无需是扩散或流模型，这是它与生成式动作策略优化的关键区别。

xTED 是更直接的轨迹编辑对照，DARC、DARA 是奖励修正对照；[SB Flow](../2409.09347_sb_flow/) 属于相关的非配对数据翻译工作，本文未验证替换成它即可处理视觉或点云。SB 在这里的优势是源域转移天然提供信息起点，代价是每个训练转移都要经过额外采样。

## 与 SB×RL 的关联（对我们选题的启示）

“SB 翻译状态转移后训练跨域策略”这一组合已有明确先例，后续工作应检验桥是否真在修正动力学。可比较整向量翻译与固定状态、动作后仅翻译下一状态，沿当前策略访问分布测转移误差、回报和目标数据支持度；低支持区域单列，避免平均误差掩盖策略探索造成的偏移。另一个实验针对动作成本：在原任务上添加可计算的控制代价，对比只用状态对的奖励模型与显式保留动作的模型，并记录奖励误差如何改变策略行为。两组实验都保留原文的周期更新和模仿正则，使用相同目标示范与源域交互预算，才能把改进归因到条件对齐或奖励建模，而非额外数据。目标环境只用于留出评估，不能偷偷参与训练选择。

## 局限与批判

- 对完整 $[s,a,s']$ 做分布匹配并不自动保留条件动力学，状态访问分布和行为策略差异可能被一并翻译。
- 算法 1 把下一策略输入替换为翻译状态，却未说明如何同步源模拟器内部状态，后续采样究竟对应哪个状态的转移缺少实现交代。
- 奖励模型遗漏无法由状态对识别的动作成本，且源域拟合准确不能保证它在翻译后的状态对上准确。
- 性能界比较两个不同 MDP，遗漏奖励误差，也未闭合从联合分布匹配到真实目标条件转移误差的论证。
- 实验证据局限于两种状态空间任务，桥采样与周期重训的计算成本未报告，无法据此判断真机训练效率。
