# Bridging Dynamics Gaps via Diffusion Schrödinger Bridge for Cross-Domain Reinforcement Learning (BDGxRL)

> Zhang, Guo (Carleton), arXiv 2026-02。[arXiv:2602.23737](https://arxiv.org/abs/2602.23737)

## 一句话

用 DSB 把源域（可交互、有奖励）的转移在线翻译成目标域（只有无奖励离线示范）风格，配奖励调制让策略完全在源域内学出适配目标动力学的行为——SB 做 unpaired 动力学翻译进 RL 训练回路的第一篇。

## 问题与动机

跨域 RL 的现实设定：源域（模拟器）可以无限交互并给奖励，目标域（真实世界）只有一份无奖励的离线轨迹集，且两域共享状态动作空间、只差转移动力学。既有主流（DARC/DARA 一系）用分类器判别「这个转移像不像目标域」再做奖励惩罚——本质是把动力学差距变成标量惩罚，信息损失大。BDG 的主张：动力学差距是一个分布到分布的翻译问题，SB 正是 unpaired 分布翻译的原则性工具，为什么只拿它做图像？

## 方法核心

三个组件，全部在源域内闭环：

1. **DSB 动力学对齐**。用源域 rollout 数据集 $D_S$ 与目标域示范 $D_T$ 训练一个条件 DSB（IMF 求解），学「源域下一状态分布 → 目标域下一状态分布」的桥：在线交互时每个源域转移 $(s_t, a_t, s_{t+1})$ 被翻译成目标风格 $\tilde{s}_{t+1}\sim \text{DSB}_{S\to T}(\cdot|s_t, a_t, s_{t+1})$。unpaired 是关键——两域轨迹无需对齐配对，SB 只要两边各有样本。
2. **奖励调制**。目标域无奖励，直接用源域奖励会与翻译后的动力学不一致。解法：在源域数据上训练转移感知奖励模型 $R(s_t, s_{t+1})$（奖励由状态变化决定），对翻译后的转移打分：$\tilde{r}_t = R(s_t, \tilde{s}_{t+1})$——奖励与目标动力学保持一致。
3. **目标导向策略学习**。翻译后的转移 $(s_t, a_t, \tilde{r}_t, \tilde{s}_{t+1})$ 进 replay buffer，SAC 照常训练；策略用目标示范做 BC 初始化。附性能界的理论分析（学到的目标策略与最优目标策略的差距由翻译误差与奖励模型误差控制）。

## 实验与证据

- MuJoCo 跨域基准（改重力/摩擦/形态参数制造动力学差距）：一致超过 DARC、VGDF、PAR 等 SOTA 跨域 RL 基线，动力学偏移越大优势越明显。
- 实验设计评价：设定干净（共享状态动作空间、只差动力学），基线覆盖了分类器惩罚与模型差距两类主流；但全部是 MuJoCo 状态空间任务——「sim-to-real」的真正难点（视觉域差距、真机噪声）没有被触碰，DSB 翻译的是低维状态而非像素/点云。

## 与 SB×RL 的关联（对我们选题的启示）

BDG 占掉了「SB 翻译状态转移 + 跨域 RL」的组合，但它的形态是保守的：(1) **翻译对象是低维状态**——把 DSB 换成像素/点云级翻译（SB Flow 的规模化能力），做真正的 sim-to-real 视觉桥，竞争格局审计（2026-08）显示这条线是三条 SB×RL 进路中唯一无直接后续的，窗口还开着；(2) **桥与策略解耦**——DSB 训完就冻结，翻译误差不随策略分布漂移而更新，「策略感知的桥」（桥的耦合按当前策略的访问分布加权）是明显的下一步；(3) **奖励调制是拼接件**——把奖励直接写进 GSB 的路径费用（GSBM 的 $V_t$），翻译与奖励对齐可以一体化；(4) 理论性能界的松紧依赖翻译质量，而 SB 翻译在分布外状态（策略探索出的新区域）的行为没有分析——这是真机部署前必须回答的问题。

## 局限与批判

- 「跨域」实验全部是 MuJoCo 参数扰动，状态空间低维且两域共享——离 sim-to-real 的宣称距离很远。
- DSB 每步在线翻译引入推理开销（多步采样），训练墙钟成本论文没有正面报告。
- 目标示范被同时用于 DSB 训练与 BC 初始化，示范质量/数量的敏感性消融不足。
- 奖励模型假设奖励由 $(s, s')$ 决定，动作依赖奖励的任务直接失效。
