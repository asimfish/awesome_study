# Diffusion Policies as an Expressive Policy Class for Offline Reinforcement Learning

> Wang, Hunt, Zhou, ICLR 2023。[arXiv:2208.06193](https://arxiv.org/abs/2208.06193)

## 一句话

扩散行为克隆与穿过采样链的Q梯度联训，让多步隐式策略同时承担拟合与改进：Gym平均分88.0对CQL的77.6，给桥策略立下的门槛已是无需动作似然的多模态价值优化，新增耦合必须拿出同预算收益。

## 问题与动机

离线 RL 要提高动作价值，又不能追逐数据之外被高估的 Q 值；行为正则若拟合错了分布，就会把策略约束在错误区域。混合多个行为策略收集的数据常有多个动作模式，单高斯拟合可能在模式之间的低密度区域分配大量概率，动作均值也未必可用。

论文区分了策略表达力不足和正则方式不当：BEAR 的 MMD 本身没有单模态假设，问题还包括所用 Tanh-Gaussian 策略，以及先克隆行为分布、再约束新策略引入的拟合误差。Diffusion-QL 直接在同一个扩散模型中耦合行为拟合和价值改进，省去单独学习行为模型的阶段。

## 方法核心

策略以状态为条件，从高斯噪声逐步去噪得到单个动作。$a^i$ 的上标表示扩散步，末端 $a^0$ 才是送入环境的动作，不能把整条去噪链的联合分布当作动作边缘分布。噪声预测器的行为克隆目标为：

$$
\mathcal L_d(\theta)=\mathbb E_{i,\epsilon,(s,a)}
\left\|\epsilon-\epsilon_\theta\!\left(\sqrt{\bar\alpha_i}a+
\sqrt{1-\bar\alpha_i}\epsilon,s,i\right)\right\|^2.
$$

其中 $(s,a)$ 来自离线数据集 $\mathcal D$，$i$ 均匀抽取扩散步，$\epsilon$ 是标准高斯噪声，$\bar\alpha_i$ 是前向加噪过程的累计信号保留系数。一次克隆更新只需抽一个噪声层级，价值更新则要采样完整反向链。策略总目标为：

$$
\mathcal L(\theta)=\mathcal L_d(\theta)-\alpha
\mathbb E_{s\sim\mathcal D,a^0\sim\pi_\theta}[Q_\phi(s,a^0)],
\qquad
\alpha=\frac{\eta}{\mathbb E_{(s,a)\sim\mathcal D}|Q_\phi(s,a)|}.
$$

这里 $\eta$ 控制价值项强度，归一化分母不参与求导。动作采样可重参数化，所以 Q 对动作的梯度穿过整条去噪链更新策略；这发生在训练期，不是在每次执行时另加 Q 引导。Critic 用双 Q 网络及目标网络的 Bellman 回归更新，部分 AntMaze 任务还使用 max Q backup，不能把全部成绩归于策略分布的替换。

克隆损失是软分布正则，不保证生成动作严格落在数据支撑集内。论文在 D4RL 使用 5 步去噪以折中计算与表现；步数消融显示更多步骤能改善拟合，而 5 步已能取得较好控制分数。

## 在谱系中的位置

它沿用 [DDPM](../2006.11239_ddpm/) 的噪声预测训练，延续 TD3+BC 的“价值最大化加行为正则”思路，关键改变是让多步隐式策略承担两项损失。Q 加 BC 的思想早于本文，不能把整个范式归为它首创。

与 [Diffuser](../2205.09991_diffuser/) 的轨迹生成与规划相比，本文是状态条件的单动作、无模型策略优化；与纯模仿学习的区别是价值更新可偏离行为频率。这条路线给 SB 策略留下的基准很直接：新增桥结构必须胜过一个已经能拟合多模态、又无需动作似然的策略。

## 与 SB×RL 的关联

可做一个受控替换实验：把扩散动作生成器换成状态条件的随机桥，保持离线数据、critic、价值权重、网络规模和采样步数一致，用行为拟合项约束动作分布，再让末端 Q 的梯度穿过可重参数化的桥采样链。若价值更新改变终端动作边缘，就要明确软端点约束；仅有可导采样器不构成 SB。该实验检验桥的参考过程与耦合是否改善优化，而不是比较两个预算不同的生成器。

另一个切口是把四模式 bandit 改成可控制缺失模式的数据集，同时记录高价值模式命中率、数据外动作比例和实际回报，再移到同一 AntMaze 设置。若 SB 只提高 Q 估计却增加数据外动作，就没有解决本文暴露的外推问题；若在相同采样成本下稳定保留可行模式，才有继续做机器人动作块的理由。这些是待检验方案，本文未做 SB 实验。

## 局限与批判

- 附录 G 报告 5 步策略的动作推理可比单步前馈策略慢四至五倍，快速闭环控制会直接承担这笔延迟。
- 行为克隆只是软正则，错误 critic 仍可把可导生成器推向数据之外，论文没有支撑集保持保证。
- $\eta$ 和 max Q backup 按任务调整，跨域领先不等于同一套策略正则强度可以直接迁移。
- 用克隆损失第二或第三低的检查点替代回报选模依赖经验相关性，损失更小不意味着任务价值更高。
- 证据限于低维状态输入和仿真任务，未验证视觉条件、长动作块或真实机器人上的计算与收益平衡。
