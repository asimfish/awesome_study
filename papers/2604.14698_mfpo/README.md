# Mean Flow Policy Optimization (MFPO)

> Dong, Zhang, Cheng (中科院自动化所), ICML 2026。[arXiv:2604.14698](https://arxiv.org/abs/2604.14698)

## 一句话

MFPO 用平均散度网络近似动作似然、用有效样本量加权的速度估计训练两步 MeanFlow 策略，把最大熵 RL 的主要采样成本压下来，但保留下来的似然偏差仍是其理论与实践之间的缺口。

## 问题与动机

MeanFlow 学习整段平均速度，适合少步生成，却没有自动解决最大熵 RL 的两项需求：soft Bellman 目标和熵调节需要动作似然，策略改进则要拟合由 Q 函数定义、无法直接采样的 Boltzmann 分布。只替换动作头，训练信号仍然缺失。

MFPO 因而同时学习速度与似然近似，并用重要性采样构造速度回归目标。其问题意识明确：减少生成步数的同时，要保住熵评估与策略改进所需的分布信息，否则加速会改变优化目标。

## 方法核心

**用平均速度表示策略。** 给定状态 $s$，$u_\theta(s,a_t,r,t)$ 表示生成时间区间 $[r,t]$ 的平均速度；对角线 $u_\theta(s,a_t,t,t)$ 给出瞬时速度 $v_\theta$。从时间 1 的高斯噪声向时间 0 的动作采样，默认分两段更新；生成时间与环境交互步数无关。

**平均散度网络 ADN。** 连续 ODE 的换元公式把动作对数密度写成先验对数密度加散度积分，ADN 学习该积分除以区间长度后的平均值。原文式（18）的实际少步估计为

$$\log\pi_\theta(a_0\mid s)\approx\log p_1(a_1)+\frac1T\sum_{i=1}^T\delta_\omega(s,a_{t_i},t_{i-1},t_i),\qquad t_i=i/T.$$

这里 $\delta_\omega$ 是平均散度网络，$T$ 是采样步数；默认 $T=2$，所以每段各调用一次 ADN，不能说整个似然只需一次前向。训练以 Skilling–Hutchinson 迹估计提供瞬时散度监督，再通过平均散度恒等式回归；迹估计无偏，不代表训练后的似然估计无偏，动作路径与散度网络都存在近似误差。

**两套 SNIS 按 ESS 加权。** Boltzmann 条件分布对应的瞬时速度可写成条件期望。MFPO 分别用当前策略和依赖带噪动作的高斯提议做自归一化重要性采样，再按有效样本量 ESS 合并速度估计；高斯提议更适合靠近数据端的时间，当前策略补充接近噪声端的高 Q 区域。默认两组样本数为 16 和 32，自适应的是估计器权重，不是采样比例。

最终把估计速度放入 MeanFlow 回归目标，critic 用含熵的 Bellman 目标更新，并自动调节温度。完整实现还使用 C51 式分布 critic；评估时从 10 个动作候选中选 Q 值最高者，训练的随机策略与报告回报的执行规则不能混为一谈。

## 在谱系中的位置

MFPO 连接 [MeanFlow](../2505.13447_meanflow/) 的少步生成、[SAC](../1801.01290_sac/) 的最大熵框架，以及 MaxEntDP/SDAC 的 Boltzmann 条件速度估计。相对只靠 Q 梯度推动动作的生成式 actor，它试图保留显式的熵与分布目标。

附录 B.4 给出 SNIS 的渐近偏差和方差分析，B.5 的收敛论证要求准确似然、足够表达能力和无限采样；主文也承认，目标分布落在策略类之外时，速度回归的最优解通常不等于反向 KL 投影。这是方法真实的理论边界，不能把 soft policy iteration 的标准定理无条件转移过来。

[FLAC](../2602.12829_flac/) 可作为路径正则路线的对照，[DMPO](../2601.20701_dmpo/) 则属于策略梯度路线；本文没有与二者直接比较，不能把路线差别写成已经分出胜负。

## 与 SB×RL 的关联

可把 ADN 用于 SB 对应的确定性概率流 ODE，在低维桥上用精确密度或高精度数值积分作参照，比较两步估计的对数密度误差、熵误差与额外耗时；随机桥的 SDE 漂移不能直接代入 ODE 散度公式，必须先明确对应速度场和密度关系。该实验先判断低成本似然是否可信，并单独检查低密度动作区域，避免平均误差掩盖重要性权重的极端失真。

再固定动作生成器、critic 和交互预算，对比 ADN 驱动的 soft Bellman 更新与路径正则更新，检查密度误差是否引起 Q 偏差、模式收缩或回报下降。旧策略动作在新策略下的密度还需要额外求值，本文随采样计算自身似然的流程不等于直接获得 PPO 比率；因此应先复现离策略熵正则实验，再讨论迁移到 PPO。两项实验都要计入候选生成和评分的完整预算。

## 局限与批判

- 回归目标在受限策略类中不等于 KL 投影，理想收敛命题没有给有限样本、有限网络的单调改进保证。
- ADN 误差同时进入 soft Bellman 目标与策略提议的重要性权重，现有局部密度检验没有量化这条反馈中的误差放大。
- 两步仍是推荐配置，原文的一步消融表现较差，MeanFlow 表示本身没有消除在线 RL 的拟合难度。
- 评估依赖十候选 Q 筛选，0.46 ms 的单样本生成速度不足以代表完整执行策略成本。
- 控制证据集中于状态输入仿真，未覆盖视觉动作块、精细操纵或真机上的似然估计与时延约束。
