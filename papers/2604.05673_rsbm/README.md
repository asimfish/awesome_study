# Rectified Schrödinger Bridge Matching for Few-Step Visual Navigation (RSBM)

> Wuyang Luan, Junhui Li, Weiguang Zhao, Wenjian Zhang, Tieru Wu, Rui Ma（吉林大学、重庆大学、利物浦大学、Changchun GenY Technology），arXiv 预印本，v3 2026-05-27（IEEE TMM 格式稿）。[arXiv:2604.05673](https://arxiv.org/abs/2604.05673)

## 一句话

学习先验与桥核方差缩放联手，把少步桥式策略推到闭环验证：室内导航仿真三步成功率92%，足以成为具身桥策略的对照锚点，却尚不能把监督导航的成绩算作奖励优化的胜利。

## 问题与动机

单目导航需要根据历史观测和目标图像预测未来路点，同一视觉条件可能允许多条可行路线。生成策略能表达这种歧义，但多次去噪增加推理开销；直接减少积分步数，又容易破坏轨迹质量。

NaviBridger 已用学习先验替代纯噪声，减少从粗轨迹到目标轨迹的修正幅度。RSBM 在此基础上控制桥中间状态的方差，并直接回归速度场。要检验的是：先验已经有信息时，桥内噪声是否仍妨碍少步推理，以及减少噪声会不会丢掉可行模式。本文是监督轨迹学习，没有强化学习更新。

## 方法核心

**条件先验确定起点。** 视觉编码器把观测序列与目标图像压成上下文 $c$；条件 VAE 生成粗轨迹 $a_T=g_\psi(z,c)$，模型再从生成时间 $T$ 积分到 $0$，输出 $a_0$。数据轨迹是 $H\times2$ 的二维路点序列，生成时间不等于车辆运动时间。训练使用后验 $q_\psi(z\mid c,a_0)$，测试从标准高斯采样；这属于条件 VAE 的设计，不能仅凭两者不同就断言训练失效。

**缩放桥核方差。** 原文式（3）至（5）定义：

$$
q_\epsilon(a_t\mid a_0,a_T)=\mathcal N\!\left((1-s_t)a_0+s_ta_T,\;\epsilon t^2(1-s_t)I\right),\qquad s_t=t^2/\sigma_{\max}^2,\quad T=\sigma_{\max}.
$$

$\epsilon\in(0,1]$ 缩放方差，$t=0,T$ 两端方差均为零；$\epsilon\to0$ 时得到给定端点对之间的确定插值。这里能直接证明的是条件核收缩，若要称其为全局 Monge 最优传输，还需证明训练端点耦合最优。

**速度结构不变，但训练分布改变。** 定理 1 给出条件目标：

$$
v_t^*=\dot\mu_t+\frac{1-2s_t}{t(1-s_t)}(a_t-\mu_t),\qquad \mu_t=(1-s_t)a_0+s_ta_T.
$$

系数不显含 $\epsilon$，因此可沿用同一网络结构；但 $a_t$ 的分布随 $\epsilon$ 改变，不能推出同一组训练权重适用于所有强度。网络通过条件流匹配学习 $v_\theta(a_t,t,c)$，推理无需已知真实端点。

命题 1 给出固定端点下的目标速度协方差 $\operatorname{Var}(v_t^*\mid a_0,a_T)=\epsilon(1-2s_t)^2/(1-s_t)\,I$。这说明方差随 $\epsilon$ 线性缩小；它没有单独证明网络误差、边缘速度曲率或有限步积分误差同幅下降，且表达式在 $t\to T$ 时仍发散。实现使用 Heun 求解器与 Karras 时间网格，默认 $\epsilon=0.5$。即使使用确定性 ODE 求解器，随机先验仍可产生多模态输出；确定性积分并不意味着输出策略没有随机性。

## 实验与证据

- 表 I 的 Custom Indoor 中，RSBM 的 3 步结果为 MSE 1.90、余弦相似度 0.945、成功率 92%；同为 3 步的 NaviBridger 为 MSE 12.00、成功率 35%，MSE 比值约 6.3；表 IV 给出的 RSBM 成功率为 3 个种子的 $92\pm2\%$。
- 与 NaviBridger 的 10 步相比，RSBM 3 步的室内成功率更高，但 MSE 略差：1.90 对 1.82；论文标注 NFE 从 19 降至 5，相差 3.8 倍，不能把“3 步”写成“3 次网络调用”。
- CitySim 的 RSBM 3 步成功率是 68%，不能沿用室内的 92%；两套仿真报告闭环成功和碰撞指标，五套真实导航数据只做开环路点预测；表 II 的平均 MSE 是 1.19，平均余弦相似度是 0.934。
- 表 III 隔离预测目标：室内 3 步时，速度预测 MSE 为 1.90，端点预测为 2.95；表 VII 中仅先验、纯高斯加矫正桥、先验加矫正桥的成功率分别为 45%、62%、92%，说明性能依赖两个组件共同作用。

主结论应落在“少步导航有效”：这些表支持在指定预算下超越 NaviBridger，未证明所有精度指标都领先，也未证明更小的桥核方差保留了全部动作模式。

## 在谱系中的位置

直接前身是 NaviBridger 的信息先验导航桥；[DSBM](../2303.16852_dsbm/) 与 [GSBM](../2310.02233_gsbm/) 提供桥匹配背景，[Flow Matching](../2210.02747_flow_matching/) 提供速度回归接口。RSBM 的实际改动是缩放条件桥方差并结合学习先验，而非运行迭代边缘匹配求解器。

[Rectified Flow](../2209.03003_rectified_flow/) 同样关注易积分的传输路径，但直线条件插值、迭代 reflow 和 RSBM 的方差缩放不能混称一种操作。RSBM 是少步桥式具身策略的可用文献锚点，本文证据不足以支持“第一个”或“唯一”。

## 与 SB×RL 的关联（对我们选题的启示）

可把 RSBM 用作导航或操纵的监督初始化，再比较固定桥噪声与可调桥噪声下的奖励微调，固定先验、数据与网络调用预算，同时测闭环成功率、碰撞率和多路线覆盖；这能检验降低条件方差是否只是用模式丢失换取少步精度。若接入 GSB-MDPO，须先给 ODE 策略构造可计算的随机转移，并在一次新旧策略比较中共享扩散系数，不能直接把核参数的变化塞进漂移均方差公式。另一个实验应针对跨环境先验：冻结视觉编码器，分别固定和微调条件先验，比较桥更新能否修复新场景中的错误路点。评估时应保留相同目标下的多条可行示范，避免把偏离单条真值的安全轨迹误判为失败。只有把先验迁移与路径优化拆开，才能判断 SB×RL 的收益来自奖励驱动的桥更新，还是先验重新拟合。

## 局限与批判

- 定理只证明条件目标的结构与方差性质，未建立缩小 $\epsilon$ 必然降低学习后边缘场积分误差的完整链条。
- 式（20）计算的是固定时刻的条件高斯 KL，不能充当整条路径的 KL 代价，文中的 SB 最优性与确定性 OT 解释也未补上端点耦合证明。
- Heun 的式（11）至（12）在预测点求第二次速度、却返回校正点，正文所称跨步 FSAL 复用不能直接成立，标注的 NFE 需结合代码核验。
- 原文把 3.8 倍 NFE 缩减直接写成同倍端到端加速，忽略自身提到的固定感知开销，Jetson 延迟与控制频率的对应关系也未解释。
- 闭环测试仅含静态障碍仿真，条件先验按数据集训练且不支持零样本迁移，多模态保持也缺少覆盖率指标。
